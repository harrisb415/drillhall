## Source archive checksums

`git archive` is deterministic for a given tag and format, so these are
reproducible by anyone with the repo — no separately hosted download to
trust:

    git checkout v1.0.0
    git archive --format=tar.gz --prefix=comptia-platform-1.0.0/ -o comptia-platform-1.0.0.tar.gz v1.0.0
    git archive --format=zip     --prefix=comptia-platform-1.0.0/ -o comptia-platform-1.0.0.zip     v1.0.0
